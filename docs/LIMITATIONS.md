# Limitations

- All inputs and references are fictitious; no substantive conclusion about a real population can be drawn.
- Demo parameters are not externally calibrated or validated.
- The model omits temporary stopout and course withdrawal in the supplied configuration.
- Non-continuity is a simulated terminal event and should not be interpreted as an observed cause.
- The grade mechanism is stochastic and illustrative, despite deterministic reproducibility for a fixed seed.
- The analysis-ready workbook is relational output for exploration, not a single machine-learning matrix.
- Generated associations are not causal effects.
- Privacy checks reduce accidental disclosure risk but do not replace an independent release review.
